# Imagens da identidade

Para trocar a foto ampla do casal, substitua `couple-background-placeholder.webp`
por outra imagem com o mesmo nome. Prefira uma foto horizontal em proporção 16:9,
com pelo menos 1600 px de largura e o casal mais próximo do lado direito.

O arquivo `floral-corner.webp` contém o arranjo floral usado nos cantos do site.
